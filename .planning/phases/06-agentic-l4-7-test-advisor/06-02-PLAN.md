    **agent-service/api_client.py** — Async httpx client with retry logic:
    - Class `BackendAPIClient(base_url: str, timeout: int = 10)`
    - `async def get_cyperf_apps() -> list[dict]` — calls `GET {base_url}/cyperf-applications`, returns `data["results"]`
    - `async def get_cyperf_strikes() -> list[dict]` — calls `GET {base_url}/cyperf-applications/strikes`, returns `data["results"]`
    - Both methods use `@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=1, max=5), reraise=True)` from tenacity
    - Each call uses `async with httpx.AsyncClient() as client` with `timeout=self.timeout`
    - On HTTP error: `response.raise_for_status()` — let tenacity handle retries
    - On final failure after retries: re-raise (callers catch and return graceful response)
    - Use `httpx.AsyncClient`, never `requests` — per architecture invariant

    **agent-service/ranking.py** — Hybrid keyword + fuzzy ranking:
    - `class RankedProfile(NamedTuple)`: `profile_name: str`, `profile_type: str`, `score: float`, `rationale: str`
    - `def rank_profiles_hybrid(profiles: list[dict], user_scenario: str, top_k: int = 3) -> list[RankedProfile]`
    - Each profile dict has at least `{"strike_name": ...}` (from strikes endpoint) or `{"name": ..., "description": ...}` (from apps endpoint)
    - Normalize: for strikes, set `name = profile["strike_name"]`; for apps, use `profile["name"]`
    - Factor 1: keyword presence — scenario words (len>3) intersected with profile name/description words, normalized 0-1
    - Factor 2: `rapidfuzz.fuzz.token_sort_ratio(profile_text, scenario_lower) / 100.0`
    - Composite: `0.6 * keyword_score + 0.4 * fuzzy_score`
    - Rationale template: score>0.7 → "Strong match: {name} directly addresses your scenario.", score>0.4 → "Relevant match: {name} covers key aspects of your testing objectives.", else → "Potential match: {name} may address parts of your scenario."
    - Return `sorted(scored, key=lambda x: x.score, reverse=True)[:top_k]`

    **agent-service/recommendation_agent.py** — Orchestration layer (NOT Gemini function-calling in this plan; use prompt-with-context approach for reliability and simplicity):

    Design rationale: Gemini automatic function-calling is ideal but requires async SDK setup and increased complexity for a single-phase delivery. Instead, use the **prompt-with-context** pattern: fetch all candidate profiles first, then ask Gemini to rank and write rationale for the top-k from `ranking.py`. This is deterministic in data fetching (no Gemini tool-calling ambiguity) and leverages Gemini for what it does best — natural language rationale.

    ```python
    class RecommendationAgent:
        def __init__(self, settings: AgentSettings):
            self.settings = settings
            self.api_client = BackendAPIClient(
                base_url=settings.backend_api_url,
                timeout=settings.backend_timeout_seconds,
            )
            import google.generativeai as genai
            genai.configure(api_key=settings.gemini_api_key)
            self.model = genai.GenerativeModel("gemini-2.0-flash")

        async def recommend(self, req: L47ScenarioRequest) -> list[Recommendation]:
            """
            1. Fetch candidate profiles based on testing_focus (deterministic routing)
            2. Rank with hybrid algorithm
            3. Call Gemini to generate rationale for top-k
            4. Return structured Recommendation list
            """
            candidates = await self._fetch_candidates(req.testing_focus)
            if not candidates:
                return []

            user_scenario = f"{req.use_case} {req.objectives} {req.timeline}"
            ranked = rank_profiles_hybrid(candidates, user_scenario, top_k=3)

            return await self._generate_recommendations(ranked, req)

        async def _fetch_candidates(self, testing_focus: str) -> list[dict]:
            """Fetch relevant profiles based on testing_focus. Returns empty list on backend failure."""
            try:
                if testing_focus == "app_performance":
                    items = await self.api_client.get_cyperf_apps()
                    return [{"name": i["name"], "description": i.get("description", ""), "type": "application"} for i in items]
                elif testing_focus == "security_attacks":
                    items = await self.api_client.get_cyperf_strikes()
                    return [{"name": i["strike_name"], "description": i["strike_name"], "type": "strike"} for i in items]
                else:  # both
                    apps = await self.api_client.get_cyperf_apps()
                    strikes = await self.api_client.get_cyperf_strikes()
                    app_dicts = [{"name": i["name"], "description": i.get("description", ""), "type": "application"} for i in apps]
                    strike_dicts = [{"name": i["strike_name"], "description": i["strike_name"], "type": "strike"} for i in strikes]
                    return app_dicts + strike_dicts
            except Exception as exc:
                logger.warning("Backend API fetch failed: %s", exc)
                return []

        async def _generate_recommendations(
            self, ranked: list[RankedProfile], req: L47ScenarioRequest
        ) -> list[Recommendation]:
            """
            Use Gemini to generate 2-3 sentence rationale for each ranked profile.
            Falls back to ranking.py template rationale if Gemini call fails.
            """
            recommendations = []
            for i, profile in enumerate(ranked, start=1):
                try:
                    rationale = await self._gemini_rationale(profile, req)
                except Exception as exc:
                    logger.warning("Gemini rationale failed for %s: %s — using template", profile.profile_name, exc)
                    rationale = profile.rationale  # Fallback to ranking template

                recommendations.append(Recommendation(
                    rank=i,
                    profile_name=profile.profile_name,
                    profile_type=profile.profile_type,
                    rationale=rationale,
                ))
            return recommendations

        async def _gemini_rationale(self, profile: RankedProfile, req: L47ScenarioRequest) -> str:
            """
            Ask Gemini to write a 2-3 sentence rationale for why this profile matches the scenario.
            Runs synchronously via asyncio.to_thread() since google-generativeai SDK is sync.
            """
            import asyncio
            prompt = (
                f"You are a network testing expert. In 2-3 concise sentences, explain why "
                f"the Cyperf {'application profile' if profile.profile_type == 'application' else 'strike'} "
                f"named '{profile.profile_name}' is a good fit for this L4-7 test scenario:\n\n"
                f"Use case: {req.use_case}\n"
                f"Objectives: {req.objectives}\n"
                f"Timeline: {req.timeline}\n\n"
                f"Be specific to the profile name and scenario. No generic advice."
            )
            response = await asyncio.to_thread(
                self.model.generate_content,
                prompt,
                generation_config={"temperature": 0.3, "max_output_tokens": 150},
            )
            return response.text.strip()
    ```
