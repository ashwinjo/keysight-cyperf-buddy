  <name>Task 1: Implement SyncService with database recording and graceful degradation</name>
  <files>backend/services/sync_service.py</files>
  <action>
Create backend/services/sync_service.py with the following:

**Function perform_sync(session: AsyncSession, settings: Settings) -> None:**
  - Orchestrates the full sync cycle:
    1. Record attempt start: call record_sync_start(session) → sets last_run_at, status='running'
    2. Call CyperfService.sync_cyperf_cves() with retry logic
       - Immediate retry: if connection fails, retry once immediately
       - Delayed retry: if immediate retry fails, wait 5 seconds, then retry once more
       - Failure: if both retries fail, log error and proceed to record failure (don't raise exception)
    3. On successful fetch:
       - Extract CVEs from profiles via CyperfService
       - For each (cve_id, profile_name) pair:
         - Upsert to cyperf_supported_cves table
         - Use session.merge() to handle conflicts idempotently
       - Commit transaction atomically
    4. On any error during upsert (database error, etc):
       - Rollback transaction (don't corrupt database)
       - Log error with context
       - Record sync failure with error_message
    5. Record sync completion: call record_sync_complete(session, result) → sets last_completed_at, status='success'/'failed', error_message, cverf_cves_extracted
    6. Schedule next sync: compute next_scheduled_sync = now() + timedelta(hours=settings.cyperf_sync_interval_hours); record in metadata

**Graceful Degradation:**
  - If Cyperf is unreachable (exception raised by CyperfService):
    - Log error at ERROR level with retry attempt count and reason
    - DO NOT delete or modify cyperf_supported_cves table (retain all previous mappings)
    - DO NOT raise exception (let scheduler continue)
    - Record error_message in sync_metadata (e.g., "Connection timeout after 2 retries")
    - API continues serving previous data to users
  - If database commit fails during upsert:
    - Rollback transaction
    - Log database error
    - Record failure in sync_metadata
    - Don't retry (let next scheduled sync attempt recovery)

**Circuit Breaker (Claude's discretion):**
  - Track consecutive failures by querying sync_metadata
  - If 3 consecutive syncs failed, emit ERROR-level log "Cyperf sync circuit breaker: 3 consecutive failures; check controller availability"
  - Do NOT change app behavior (continue serving stale data)
  - Alert will be picked up by ops monitoring

**Logging (use Python logging + structured JSON context):**
  - INFO: "Cyperf sync started", "Fetched {N} profiles in {T}s", "Extracted {M} CVEs", "Sync completed successfully"
  - WARN: "Cyperf sync failed after retries; serving stale data", retry attempt counts
  - ERROR: Connection errors, API errors, database errors (with code/message, never credentials)
  - Include context dict: {start_time, duration_seconds, profiles_fetched, cves_extracted, error_code, retry_count}

**Error Handling Retry Logic:**
  - Immediate retry: if CyperfConnectionError raised, retry once (total 2 attempts)
  - Delayed retry: if immediate retry fails, sleep 5 seconds, retry once more (total 3 attempts)
  - After 3 total attempts fail: log error, record in metadata, move on (don't block scheduler)
  - Example: [attempt 1 fails] → [wait 0s, attempt 2 fails] → [wait 5s, attempt 3 fails] → [record failure, exit]

**Imports:**
  - from services.cyperf_service import CyperfService
  - from db.sync_metadata import SyncMetadata, record_sync_start, record_sync_complete
  - from db.cyperf_mapping import CyperfSupportedCVE
  - from sqlalchemy.orm import Session
  - import logging, asyncio, datetime

**Database Helper Functions (implement in this file or db module):**
  - async record_sync_start(session: AsyncSession) -> None — sets last_run_at=now(), status='running'
  - async record_sync_complete(session: AsyncSession, profiles_count: int, cves_count: int, error_msg: Optional[str]) -> None — sets last_completed_at=now(), status='success'/'failed', results
  - async get_consecutive_failures(session: AsyncSession) -> int — count of last N syncs with status='failed'

**Transaction safety:**
  - All database operations within a single AsyncSession transaction
  - Commit after all CVEs upserted (atomic all-or-nothing)
  - Rollback on any error
