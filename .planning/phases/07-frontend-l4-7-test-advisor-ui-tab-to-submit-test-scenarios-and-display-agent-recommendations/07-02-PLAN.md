Create a controlled form component. All four fields are always required (unlike AshRAI which has conditional fields). Use the same manual state pattern as `QuestionnaireForm.tsx`.

- State: `testingFocus` (union type), `useCase`, `objectives`, `timeline`, `validationErrors: string[]`
- `mutation = useGetL47Recommendations()` — imported from `../hooks/useAPI`
- Client-side validation before calling mutation:
  - `use_case` length >= 10 chars
  - `objectives` length >= 10 chars

- Render `validationErrors` as a red error list (dark theme: `bg-red-900/30 border-red-700/40 text-red-300`)
- Render `mutation.error` as a server error banner (same dark-theme red pattern)
- Render `mutation.isPending` loading state with spinner: `animate-spin rounded-full border-2 border-luxury-accent border-t-transparent`
- Testing focus select options must use the EXACT snake_case values the agent expects:
  ```
  value="app_performance" → display "Application Performance"
  value="security_attacks" → display "Security / Attacks"
  value="both"            → display "Both"
  ```
  Sending 'Application Profile' (AshRAI style) causes agent 422.
- Dark theme form elements: `bg-luxury-bg border border-luxury-border text-luxury-text rounded-md px-3 py-2 w-full focus:outline-none focus:ring-2 focus:ring-luxury-accent`
- Submit button: `bg-luxury-accent hover:bg-luxury-accent/90 text-white font-semibold px-6 py-2 rounded-md transition-colors disabled:opacity-50 disabled:cursor-not-allowed` — disabled when `mutation.isPending`
